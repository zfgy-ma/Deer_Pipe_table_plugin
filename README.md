# 🦌 鹿管记录插件

记录 QQ 群成员鹿管次数，自动生成月度热力图、排行榜柱状图和趣味统计报告。所有配置项均可在 MaiBot WebUI 中可视化编辑，修改触发词后重启插件即可生效。

---

## 📁 文件结构

```
Deer_Pipe_table_plugin/
├── _manifest.json         # 插件元信息（名称、版本、能力声明）
├── config.py              # 配置模型定义（WebUI 表单来源）
├── config.toml            # 运行时配置文件（用户可编辑）
├── plugin.py              # 插件主逻辑（命令、数据层、图表生成）
├── chart_template.py      # HTML/CSS 图表模板（热力图、条形图、完整报告）
├── data/                  # 打卡数据存储（按群号+月分文件）
│   └── {QQ群号}_{YYYY-MM}.json
└── chart_cache/           # 月度报告图表缓存（数据变更时自动刷新）
    └── {QQ群号}_{YYYY-MM}.txt
```

## 📖 功能详解

### 1. 文件路径展示

插件目录结构清晰，核心文件各司其职：

| 文件 | 作用 |
|------|------|
| `config.py` | 定义所有可配置项的字段类型、默认值、WebUI 显示文本（含中/英/日三语） |
| `config.toml` | 用户的实际配置值，启动时加载，WebUI 修改后自动同步 |
| `plugin.py` | 插件主逻辑：4 个命令组件、数据读写、限频检查、图表生成调度 |
| `chart_template.py` | 纯 HTML/CSS 模板，生成热力图、柱状图和完整报告，无外部依赖 |

数据文件按 `{QQ群号}_{YYYY-MM}.json` 命名，例如群 `123456789` 在 2026 年 6 月的数据文件为 `data/123456789_2026-06.json`。

---

### 2. 触发词自定义

所有功能的触发词均可在 WebUI 的 **"触发词"** 配置页中修改，支持 emoji 和中英文。

**配置路径**：WebUI → 插件管理 → 鹿管记录插件 → 配置 → 触发词

| 字段 | 默认值 | 说明 |
|------|--------|------|
| `enable_record` | `true` | 鹿管记录开关 |
| `deer_pipe_record_words` | `🦌` | 打卡触发词 |
| `enable_rank` | `true` | 排行榜开关 |
| `deer_pipe_rank_words` | `🦌排名` | 排行榜触发词 |
| `enable_personal` | `true` | 个人统计开关 |
| `deer_pipe_personal_words` | `我的🦌` | 个人统计触发词 |
| `enable_monthly` | `true` | 月表开关 |
| `deer_pipe_monthly_words` | `🦌表` | 月表基础词 |

> **注意**：修改触发词后需重启插件才能生效。

### 3. 🦌 记录打卡

群成员发送纯触发词（默认 `🦌`）时，系统自动记录一次打卡。

**工作流程**：
1. 检查功能开关是否启用
2. 检查当前群是否在白名单内（如配置了白名单）
3. 检查该成员是否在冷却期内
4. 写入群文件记录（用户 ID + 昵称 + 时间戳）
5. 回复打卡成功，附带个人本月热力图

**成功回复示例**：

### 6. 🦌 表月度报告

发送触发词查看完整月度报告图表，支持三种格式：

| 格式 | 示例 | 说明 |
|------|------|------|
| 基础词 | `🦌表` | 查询当前月 |
| 上月/本月 | `上月🦌表`、`本月🦌表` | 查询上个月或当前月 |
| 指定月份 | `🦌表 6月`、`🦌表6月` | 查询指定月份 |

**报告包含四个区域**：
1. **每日活跃热力图** — 整月每天打卡人数着色（黄→红 6 级）
2. **Top 10 柱状图** — 本月鹿管王排行
3. **趣味统计卡片** — 最活跃时段、单日最高、连续打卡王、参与人数
4. **历史总榜 Top 5** — 所有月份累计排行

### 7. 定时夜间模式

图表在指定时段自动切换为暗色主题。

**配置路径**：WebUI → 插件配置 → 夜间模式

| 字段 | 默认值 | 说明 |
|------|--------|------|
| `dark_mode` | `true` | 是否启用夜间模式 |
| `dark_start` | `21` | 夜间开始小时（0-23） |
| `dark_end` | `7` | 夜间结束小时（0-23），支持跨天 |

> 默认 21:00 ~ 次日 7:00 为暗色模式。暗色背景 `#1D1D1D`，所有图表组件颜色同步适配。

---

### 8. 自定义冷却时间

防止刷屏，每人两次打卡之间必须间隔一定时间。

**配置路径**：WebUI → 插件配置 → 限频

| 字段 | 默认值 | 说明 |
|------|--------|------|
| `cooldown_minutes` | `120` | 冷却时间（分钟），默认 120 = 2 小时 |
> 冷却期按**每人独立计算**，不同用户之间互不影响。跨月数据不共享冷却状态。

---

### 9. 自定义回复句

冷却期内打卡时的自动回复内容可自定义。

**配置路径**：WebUI → 插件配置 → 限频

| 字段 | 默认值 | 说明 |
|------|--------|------|
| `exceed_reply` | `注意身体，歇会儿吧！` | 超限时的回复内容 |

> 回复会自动拼接冷却时长，例如：`注意身体，歇会儿吧！（每 120 分钟只能记录一次哦）`

### 10. 数据保留策略

**存储方式**：
- 数据以 JSON 文件存储在 `data/` 目录
- 按 QQ 群号 + 月份分文件：`{QQ群号}_{YYYY-MM}.json`
- 每条记录包含：`user_id`、`nickname`、`timestamp`

| 字段 | 说明 |
|------|------|
| `user_id` | 用户 ID |
| `nickname` | 昵称 |
| `timestamp` | 记录时间 |

**自动清理**：

| 字段 | 默认值 | 说明 |
|------|--------|------|
| `months` | `2` | 数据保留月数 |
| `auto_cleanup` | `true` | 插件加载时自动清理过期文件 |

> 清理基于文件的最后修改时间（mtime），超过保留期限的文件在插件启动时自动删除。

---

### 11. 白名单群管理

限制插件只在指定群聊中生效。

**配置路径**：WebUI → 插件配置 → 群过滤

| 字段 | 默认值 | 说明 |
|------|--------|------|
| `allowed_groups` | `[]`（空列表） | 白名单群号列表 |

- **留空**：允许所有群
- **填写群号**：只有列表中的群号才会记录打卡和响应命令
- 每行一个群号

---

### 12. HTML 自动绘图

插件内置纯 HTML/CSS 图表模板，通过 MaiBot 的 `html2png` 渲染服务自动生成图片。

**渲染流程**：
1. 根据数据类型选择模板函数（`build_personal_heatmap` / `build_deer_pipe_rank_chart` / `build_full_report`）
2. 模板函数生成完整 HTML 字符串（内联 CSS，零外部依赖）
3. 调用 `self.ctx.render.html2png()` 渲染为 PNG 图片
4. 返回 base64 编码的图片数据
5. 通过 `send.image` 或 `send.hybrid` 发送到群聊

**图表类型**：

| 图表 | 模板函数 | 说明 |
|------|---------|------|
| 个人热力图 | `build_personal_heatmap()` | 月度日历热力图，5 级着色 |
| 排行榜柱状图 | `build_deer_pipe_rank_chart()` | Top 10 黄红渐变柱状图 |
| 完整月报 | `build_full_report()` | 热力图+柱状图+趣味统计+历史总榜 |

> 月度报告有缓存：根据打卡数据的 MD5 哈希判断是否需要重新渲染，避免重复消耗渲染资源。

## ❓ 常见问题

**Q：[IPC插件系统] [cap.render.html2png] 执行失败: 启动本地浏览器失败？**
A: 运行`uv run playwright install-deps`为自动化浏览器安装运行所需的全部操作系统级系统依赖

**Q：修改触发词后不生效？**
A：触发词修改后需要**重启插件**才能生效（因为命令正则模式在插件加载时构建）。

**Q：打卡后没有回复？**
A：依次检查：① 插件是否启用 ② 触发词是否完全匹配 ③ 当前群是否在白名单内 ④ 触发词是否完全相同(不可@) ⑤ 检查日志报错

**Q：排行榜显示"本月无记录"？**
A：当前月份还没有人打卡。发送触发词开始记录即可。

**Q：月度报告图片显示异常？**
A：删除 `chart_cache/` 目录下的缓存文件，下次查询会重新渲染。如果仍异常，检查 MaiBot 的渲染服务是否正常。

**Q：如何备份数据？**
A：复制 `data/` 目录即可。JSON 文件可直接查看和编辑。

**Q：数据能保留多久？**
A：默认保留 2 个月，可在 WebUI 的数据保留配置中调整。设为 0 或关闭自动清理则不删除。

**Q：如何让插件只在部分群工作？**
A：在 WebUI 的群过滤配置中填入允许的群号列表，留空则表示所有群均可使用。
