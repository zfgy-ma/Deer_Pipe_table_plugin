# 🦌 鹿管记录插件

记录 QQ 群成员发送 🦌 的次数，生成月度统计图表和排行榜。

## 功能

- **🦌 记录**：群成员发送纯 🦌（允许前后空格）时自动记录一次，每群独立限频
- **🏆 排行榜**：查询本月鹿王 Top 10 + 你的排名，附带柱状图
- **📊 月度图表**：热力图（每日活跃分布）+ 柱状图（Top N），支持自然语言月份查询
- **👤 个人统计**：查询个人当月次数、排名、最长连续打卡、时段偏好
- **🤖 LLM 工具**：3 个工具供 AI 调用（排行榜、月表、个人统计）
- **🎯 趣味统计**：历史总榜 Top 5、最长连续打卡、热门时段分布、单日最高记录

## 安装

1. 将 `Deer_Pipe_table_plugin` 目录放入 MaiBot 的 `plugins/` 目录
2. 重启 MaiBot 或在 WebUI 中启用插件
3. 在 WebUI 插件管理页中配置触发词和限频参数

## 配置

在 WebUI 插件配置页中可编辑以下分组：

### 插件 `[plugin]`
| 字段 | 默认值 | 说明 |
|------|--------|------|
| `enabled` | `false` | 是否启用插件 |

### 触发词 `[trigger]`
| 字段 | 默认值 | 说明 |
|------|--------|------|
| `deer` | `🦌` | 纯此 emoji 时记录一次 |
| `leaderboard` | `鹿王` | 排行榜触发词 |
| `personal` | `我的鹿管` | 个人统计触发词 |
| `monthly_prefix` | `月鹿表` | 月表命令前缀（前接月份数字，如 `6月鹿表`） |

### 限频 `[rate_limit]`
| 字段 | 默认值 | 说明 |
|------|--------|------|
| `max_count` | `5` | 每个时间窗口内最大记录次数 |
| `window_hours` | `2` | 限频时间窗口（小时） |
| `exceed_reply` | `注意身体，歇会儿吧！` | 超限回复内容 |

### 数据保留 `[retention]`
| 字段 | 默认值 | 说明 |
|------|--------|------|
| `months` | `2` | 数据保留月数 |
| `auto_cleanup` | `true` | 是否自动清理旧数据 |

## 命令

| 触发词（可配置） | 说明 |
|-----------------|------|
| 🦌 | 纯 🦌 即记录一次 |
| 鹿王 | 查看本月鹿管排行榜 |
| 我的鹿管 | 查看个人鹿管统计 |
| X月鹿表 / 上月鹿表 / 本月鹿表 | 查看指定月鹿表图表 |

## LLM 工具

| 工具名 | 说明 |
|--------|------|
| `deer_query_leaderboard` | 查询本月鹿管排行榜 |
| `deer_query_monthly_chart` | 查询指定月份鹿管统计 |
| `deer_query_personal` | 查询个人鹿管统计 |

## 数据存储

- 数据以 JSON 格式存储在 `plugins/Deer_Pipe_table_plugin/data/` 目录
- 按群号+月份分文件，文件名格式：`{group_id}_{YYYY-MM}.json`
- 图表缓存存储在 `chart_cache/` 目录
- 超过保留期限的旧数据会在插件加载时自动清理

## 卸载

在 WebUI 中禁用或删除插件即可。数据文件不会被自动删除，如需清理请手动删除 `plugins/Deer_Pipe_table_plugin/data/` 目录。
